## 实现及已验证范围

## 复现及正式放行

Gurobi 13.0.1、Python 3.12.7，实际求解使用学术许可证。工作簿为只读 XLSB，使用专用解析器 pyxlsb。

```powershell
python -m pip install -e ".[test,v25-source]"
python -m examples.run_v25_phase1 --source "<原始 XLSB 或包含它的 ZIP>" --out "<新的输出目录>"
python -m pytest -q --basetemp "<新的测试临时目录>"
```

实际机器可读结果见 [audit.json](../artifacts/v25_phase1_20261110/audit.json)，同目录保存五份原始求解日志。已发现的本地 `paper_scale_instance_v1.zip` 有 715 个筛选订单及物理数量缩放，无法替代冻结的 V2 实例。需提供 `paper_scale_v2/manifest.json`，核对正式预算、容量和显式风险场景后才能接通正式模型入口并给出正式规模数值认证。算法阶段的门槛仍由独立评审决定。

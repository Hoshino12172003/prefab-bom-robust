# V3.2 数学规格补充

本规格以 V3.1 最终规格为基线，仅替换准备期能力、准备库存容量和 Gate 3 准入接口。沿用原物理网络、BOM、需求、提前期、91 个候选状态、整数物料流和两阶段时序。Gate 1、Gate 2A 与 Gate 2B 证据按原场景保留。

## 准备期能力

对每个资源 a，取原始第 61–74 期能力的含零均值 C_nom[a]，证据等级为 TRANSFORM_MEAN_INCLUDING_ZERO。定义 C_gross[a] = C_nom[a]。准备活动获得的能力为 C_prep[a,t] = alpha[a] C_nom[a]，其中 0 ≤ alpha[a] ≤ 1。alpha 是分配给准备活动的名义能力比例，证据等级为 SCENARIO_PARAMETER。允许统一比例和资源特定比例。

公开数据缺少准备期正常业务占用，因此 EMPIRICAL_RESIDUAL_CAPACITY = NOT_IDENTIFIED。Gate 3 准入采用该证据标识。

## 联合准备可行域

初始保护库存和保护性在途流为零。允许从原合法外部投入节点发运。一次发运或加工按事前时段消耗完整 BOM，在出发期加提前期时到货。各节点、物料、期逐期守恒，终端保护库存 b[np] 等于准备窗口末的增量库存。所有 91 个 b 在同一网络中竞争能力。每条资源和时期的全部 SKU 流量合计不超过 alpha[a] C_nom[a]。沿用 V3.1 的时段和零提前期约定。

三种终端电芯库存按 b_c1 = 10 x_C、b_c2 = 6 x_C、b_c3 = 4 x_C 同时形成。Pack 使用实际加工流。Seat 的四种组件按原始 SKU 逐一转换。分别最大化形成量得到的 Gate 2B 投影不能相加作为联合库存。

## 库容

K_eff[np] = min(K_tech[np], K_scenario[np])。期末同时保留原先已有的正常期初库存空间。源模型 99999 标记为 SOURCE_MODEL_TECHNICAL_CEILING。缺少原始库容的五个 T1 位置及四个 OEM Seat 状态使用准备窗口内合法到达量的有限技术上界。局部情景上限与技术上界均无实测物理库容证书。

T1 Pack 与四个 T1 Seat 支持 restrictive、base、relaxed 和 technical-bound-only。前三者采用 K_scenario[np] = kappa qbar[np]，qbar 为该 SKU 合法进入弧的名义总吞吐上界。规范化认证网格 kappa = 0、0.5、2 仅用于测试，证据等级 SCENARIO_PARAMETER。SKU 仍共享入库、生产及运输弧能力。

OEM Seat 的四个 SKU 共享总库容 delta × 2000，delta ∈ {0, 0.5, 1, 2}。需求尺度 2000 源于原始订单，delta 属于 SCENARIO_PARAMETER。共享上限用于保护库存期末状态，准备期中也执行同一容量情景。

## Gate 2C 与 Gate 3

Gate 2C 先验证正权重联合缓冲价值，再约束材料资本预算。采用 V3.1 的类别级价值，三种电芯只按完整 kit 计价一次。证据等级为 V3.1 类别校准或代理。规范化预算仅服务于认证。

原 Gate 2B 的 OEM Seat 上界为零，对应 delta=0。正 delta 扩大该位置可行域。逐项比较仍按 C2C-07 原验收要求记录。C2C-10 的可比单位置复现须沿用原库存口径。三种电芯的可比目标使用一组完整 kit，字面单状态同时另测。改变验收口径需要明确决策。

所有前置 Gate 的指定检查及 Gate 2C 均通过，实测剩余能力标记 NOT_IDENTIFIED，情景证据均已分级时，方可判定 READY_FOR_GATE3 = TRUE。

## 2. 第 59 期短缺如何进入第 60 期状态

| 原表与状态 | 源数量 | 进入窗口的途径 |
|---|---:|---|
| `initial_inventories`，OEM `zp7` | 52 个 BEV 电池包 | 第 60 期末在库 |
| T1 电池包库 | 0 个电池包 | 第 60 期末无正的在库量 |
| `initial_flows`，T1 → OEM | 200 个包 | 第 60 期发运，第 61 期到 OEM |
| `initial_flows`，电池包生产 → T1 | 159 个包 | 第 60 期发运，第 61 期到 T1，最早第 62 期到 OEM |
| `initial_inventories`，电池包生产端 | 930 / 558 / 372 个电芯 | 按 10 / 6 / 4 配方形成 93 个包 |
| `initial_flows`，电芯在途，第 46 期发运 | 9,470 / 5,682 / 3,788 个 | 第 66 期到包生产端，947 套，最早第 68 期到 OEM |
| `initial_flows`，电芯在途，第 53 期发运 | 4,220 / 2,532 / 1,688 个 | 第 73 期到包生产端，422 套，最早第 75 期到 OEM |
| `initial_flows`，电芯在途，第 60 期发运 | 4,240 / 2,544 / 1,696 个 | 第 80 期才到包生产端 |

模型内没有直接补入下游电芯或 BEV 电池包的入口。电芯外部流入只允许在 20 期运输弧起点，因此窗口内新发运最早第 81 期到包生产端。每辆 BEV 消耗一个电池包。以第 74 期为末期，可交付 BEV 的供应上界为 `52 + 200 + 159 + 93 + 947 = 1,451`，对应 `3,003 − 1,451 = 1,552`。两段各一期的下游提前期阻止第 73 期电芯对该窗口的 BEV 交付作出贡献。 [源表库存和历史在途](../artifacts/v25_phase15_20261110_150354/battery_initial_and_transit.csv)

因此 `NOM` 是 **post-shortage nominal**。其乘子表示在观测到的第 60 期状态之上没有额外的情景扰动。工作簿给出了短缺后的库存和尚有效的发运记录，未单列第 59 期的质量事故或未受影响数量。Table 3 的 `s = 860` 属于原论文的短缺记账，无法从公开表逐件映射到三种电芯或还原无事故库存。结论依据来源、时点和可重放的数量守恒，未补入任何供应量。 [原论文 Table 3、Figure 11](https://www.researchgate.net/publication/343539617_Optimisation_model_for_multi-item_multi-echelon_supply_chains_with_nested_multi-level_products)

## 4. DE B0 与 B50 的逐场景服务

两个预算的归档方案逐场景统计相同。单位服务权重均为 1，因此场景贡献值 `场景按期量 / 28,000` 同时是服务率与场景目标值。求解器最大化四个场景共用的下界，未单独最大化各场景的交付。

| 场景 | DE B0 按期量 | DE B50 按期量 | 服务率／场景目标 | BEV / 其他按期量 | 生效的可用性或产能削减 |
|---|---:|---:|---:|---:|---|
| NOM | 25,974 | 25,974 | 0.927642857 | 1,451 / 24,523 | 无新增削减 |
| L1_CERT | 25,974 | 25,974 | 0.927642857 | 977 / 24,997 | 第 66 期三种电芯可用到货减半，9,470 / 5,682 / 3,788 → 4,735 / 2,841 / 1,894 |

**固定归档返回的零缓冲时，真实唯一最坏场景是 L1_CERT。** L1 的第 66 期到货只能生产 473 个整数包，物料上界为 `411 + 93 + 473 = 977` 辆 BEV，加上 24,997 辆其他车型，得到可达到的上界 25,974。NOM B0 归档计划在 L2 和 L3 不改变任何流量即可通过回读，三者的 26,448 均达到相应物料上界。四个归档场景的实现值同时等于共用下界，不代表各自独立最优值相同。由于 B50 归档上界被反例推翻，本结论仅覆盖其返回的零缓冲方案。 [各场景完整统计](../artifacts/v25_phase15_20261110_150354/all_scenarios.csv) · [削减逐期明细](../artifacts/v25_phase15_20261110_150354/scenario_reductions.csv)

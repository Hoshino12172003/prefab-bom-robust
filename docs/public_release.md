# 公开归档及版本追溯

公开分支保留六个历史提交的顺序、消息、时间和文件树。作者、提交者身份替换为 GitHub 账号和 noreply 地址，因而公开提交 SHA 与本地原 SHA 不同。映射见 [公开清单](public_release_inventory.json)。本地原分支、原提交和冻结文件保持原样。

公开归档包含 V2.5、V3 Phase 3.2D4、91 个候选键的经济与可达性表、完整物料位置表、Seat 固定情景和理论预置诊断。D4 的单体 Direct DE 状态为内存受限，独立数学界已闭合。C4 属于理论准备诊断。

源工作簿可从 [作者数据页](https://data.mendeley.com/datasets/pr3sdy5vp3/1) 另行下载。需要数据 ZIP 的公开脚本从仓库根目录下的 `external_inputs/` 查找，文件名沿用源 ZIP。源工作簿、第三方论文全文、私有任务附件和许可证文件未随本分支发布。含本机路径、个人字段或许可证标识的公开副本已脱敏，变化文件的原始与公开 SHA-256 见 [脱敏对照](public_redaction_sha256.csv)。

阶段内的冻结 manifest 仍是原实验的证据身份。公开脱敏副本不能通过要求全部文件与本地原件逐字节相同的前置检查。引用或复算公开文件时可以使用公开校验清单。重放原冻结证书需要本地原档及源数据。完整 355 块 MPS 使用 Git LFS，普通 Git 中保留指针与原内容 SHA-256。

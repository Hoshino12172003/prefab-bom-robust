## 3. 完整 MIP Start 对照与根因

三份反例的全部变量写入 `.mst`。每组均执行保留原冻结数值设置的复跑和默认单线程复跑。冻结复跑保留 4 线程、种子 20261110、`FeasibilityTol=IntFeasTol=1e-9`、相对和绝对间隙 0。默认复跑保留 Gurobi 原始默认值，仅固定单线程并将日志写入文件。所有实际复跑都使用默认的无限时限和默认的目标、界与解数终止参数，且未传入 callback。原运行的 180 秒时限只记录在原入口模型的参数快照中，未用于复跑。

| 实例 | 起点按期量 | 原冻结数值设置结果 | 默认单线程结果 | 两次均接受起点 |
|---|---:|---:|---:|---|
| nominal B20 | 26,468 | 26,468 | 26,468 | 是 |
| nominal B50 | 26,498 | 26,498 | 26,498 | 是 |
| DE B50 | 26,024 | 26,035 | 26,035 | 是 |

六份日志都含 `Loaded user MIP start with objective ...`。最终目标及上界均未低于已接受起点，立即停止条件未触发。但名义两组停在起点，之后验证了仍有更好的可行值。保留原参数、撤掉起点时，三次都再次返回原来的低上界 26,448／26,448／25,974。该结果由 Gurobi 本身产生，写报告前已经存在。

**根因是该模型在 Gurobi 13.0.1 中对 LP 对偶最优性容差敏感，默认 `OptimalityTol=1e-6` 的求解路径可产生错误低界。** 在无起点、同模型、其他数值设置相同的条件下，将 `OptimalityTol` 收紧到 `1e-9`，三组旧低界全部消失。名义 B100 同样受影响。单独关闭 `Aggregate` 只将 B20 提高至 26,468，单独关闭 `Presolve` 可恢复 B20、B50、DE B50 的容差内最优值，B100 仍停在 26,548。因此现有证据把错误定位到了对偶容差及其与求解路径的相互作用，未定位到 Gurobi 内部某个具体变换或基迭代。预处理探针显示 B20、B50、B100 的三个缓冲变量仍存在于公开的预处理输出中。Gurobi 文档说明 `OptimalityTol` 是绝对对偶可行性容差，用于单纯形和 crossover 的改进方向检验。 [Gurobi 容差与缩放说明](https://docs.gurobi.com/projects/optimizer/en/current/concepts/numericguide/tolerances_scaling.html)

## 4. 六个冻结实例的新认证

六个实例均在无起点的 `OptimalityTol=1e-9` 对照设置下重新求解。Gurobi 均返回 `OPTIMAL`、MIP gap 0。下表同时给出其容差内的结果与冻结成本下的严格整数认证。按期量由解向量和模型目标复算。运行时间为该对照求解器时间。

| 实例 | 旧归档量 | Gurobi 容差内量 | 严格最优量及精确上界 | 严格缓冲（cell / T1 / OEM） | 时间（秒） |
|---|---:|---:|---:|---:|---:|
| nominal B0 | 26,448 | 26,448 | **26,448** | 0 / 0 / 0 | 1.453 |
| nominal B20 | 26,448 | 26,472 | **26,472** | 24 / 0 / 0 | 1.852 |
| nominal B50 | 26,448 | 26,509 | **26,508** | 60 / 0 / 0 | 1.166 |
| nominal B100 | 26,548 | 26,570 | **26,569** | 121 / 0 / 0 | 1.104 |
| DE B0 | 25,974 | 25,974 | **25,974** | 0 / 0 / 0 | 9.697 |
| DE B50 | 25,974 | 26,035 | **26,034** | 60 / 0 / 0 | 17.769 |

独立上界从 XLSB 的库存、提前期、在途和 BOM 得出。无缓冲时 NOM、L2、L3 可用的 BEV 包最多 1,451 个，L1 最多 977 个，非 BEV 需求上限 24,997。每增加一套电芯或一个预定位包，至多增加一辆交付。三个整数缓冲单价均不低于 `7177.049180327869`，因此缓冲数不超过预算除以最低单价后向下取整。对 DE 取四场景上界的最小值。这个界独立于 Gurobi 的 `ObjBound`。

以原系数的精确二进制有理数计算，61 和 122 套电芯分别超支约 `2.00e-11` 和 `4.00e-11` USD。按冻结清单的十进制字面值计算也超过预算，并得到相同整数上限。两种超支均在 Gurobi 的 `1e-9` 原约束容差内。三个边界实例的严格证书各从数值解中沿 BOM 路径移去一套电芯、一个包、一次 BEV 装配和对应交付，按原始在途、物料和时序重算库存。DE 各场景共享减一套后的第一阶段缓冲。

六份严格证书对原模型每一行以有理数逐项复算，变量界、整数性与全部约束的精确残差均为零。名义按期量和 DE 最小场景按期量分别等于独立上界，故不依赖求解器容差来判断最优性。B0 在本轮重新认证后维持原值，B100 的原最优性被新证据推翻。 [六实例认证明细](../artifacts/v25_phase16_20261110_160104/all_formal_recertification.csv) · [证书文件、参数、状态和哈希](../artifacts/v25_phase16_20261110_160104/audit.json)

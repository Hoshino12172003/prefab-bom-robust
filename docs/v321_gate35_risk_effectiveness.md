# V3.2.1 Gate 3.5 风险有效性诊断

本诊断冻结在 Gate 3 提交 `c4dc91ddec1f306f50aa8473b6e739ba471c6372`。准备网络、时序、91 个位置、BOM 和资本口径由 Gate 3 原实现提供。认证目录和历史证据随原分支保留。

## 诊断设计

先分别固定 Gate 3 的零缓冲和 29 套电芯方案，独立优化名义和每个原子事件的追索。严格可比名义审计沿用 Gate 1 的 JIT 库容；事件差分和阈值扫描沿用 Gate 3 的 δ=0.5，使各自基准与事件库存界一致。名义容量表反映一组可行最优排程。行约束在该排程取等、事件排除原排程、事件降低全局最优交付分别记录。

强度扫描固定五个资源的 Gate 3 开始期和恢复期，穷举 6 档 availability 和 5 档 duration 共 150 项。临界值定义为对同一资源及持续期，从高可用率到低可用率第一个严格降低最优交付的网格点。超过运营窗口的周期按 Gate 3 规则截断。

预先确定代表事件选择规则。按 BAT_PROD、BAT_OEM、SEAT_PROD、ENGINE_PROD、GEAR_OEM 顺序，取最先有影响的两个不同 BOM 分支。每个资源先选最短有效持续期，再选该持续期下最高的有效可用率。预算响应使用两事件的 Γ=1 风险集。Γ=0、1、2 在 0 和 250,000 USD 两档比较。整个网格与代表事件均为 `DIAGNOSTIC_SCENARIO`。

## 名义上界与预算平台

零缓冲名义运行交付全部 24,997 辆非 BEV，另交付 1,451 辆 BEV。可独立验证的物料和时间上界如下。

| 截至第 74 期可用来源 | 可支持 BEV 数 |
| --- | ---: |
| OEM 初始 52 个 Pack 和第 61 期到货 200 个 Pack | 252 |
| T1 第 61 期到货的 Pack，随后合法转运 | 159 |
| 电池生产端初始电芯 `930 / 558 / 372` 按 `10:6:4` 配套 | 93 |
| 第 66 期到货电芯 `9470 / 5682 / 3788` 按 `10:6:4` 配套 | 947 |
| 合计 | 1,451 |

Pack 生产和 T1→OEM 运输各耗一期，第 72 期是本窗口能用的最晚电芯到货期。第 73 期的 422 套电芯组合最快第 75 期才能形成 OEM Pack。运营期新发电芯最快第 81 期到生产端。由 3,003 辆 BEV 的订单量和上述上界可得 1,552 辆缺口。Gurobi 交付达到 `24,997 + 1,451 = 26,448`，所以生产、运输、库存、SKU 及组约束虽在某些行取等，放宽总装能力仍无法突破这个物料—时间上界。零缓冲见证中总装在第 71、73、74 期存在余量。该余量分布随所选最优排程变化。 [逐资源容量与取等检查](../experiments/v321_gate35_risk_effectiveness/evidence/gate35_nominal_bottlenecks.csv) · [到期队列](../experiments/v321_gate35_risk_effectiveness/evidence/gate35_due_cohorts.csv)

Gate 3 的 25 万与 100 万 USD 案使用同一个 29 套上游 kit 方案。H=23、α=0.5 时，20 期上游电芯运输只有 4 个有效准备发运时段，每期 147 个电芯单位，合计 588。每辆额外 BEV 无论通过终端电芯、T1 Pack 或 OEM Pack 备货都消耗 20 个电芯单位，因此三种形式合计最多支持 29 辆。见证达到 `26,448 + 29 = 26,477`。29 套 × 7,907.26 = 229,310.54 USD，两个预算均有余量。这是两次最大服务求解选到的同一可行策略，未另求唯一政策或最低资本。

## 原八个事件

两种固定策略分别使用零缓冲与 Gate 3 的 29 套上游 kit。在各自名义基准下，原八个单事件全部 `ΔOT = 0`，`Δservice = 0`。 [事件汇总](../experiments/v321_gate35_risk_effectiveness/evidence/gate35_event_impacts.csv) · [逐期有效能力与用量](../experiments/v321_gate35_risk_effectiveness/evidence/gate35_event_period_impacts.csv)

| 事件 | 影响期 | 在两个方案下均观察到的解释 |
| --- | --- | --- |
| BAT_UP | 67–70 | 新发运无法在窗口内到货，`has_window_arrival=False`。 |
| BAT_PROD | 64–68 | 原排程被排除，受扰生产行取等，重排后仍达到名义总交付。 |
| BAT_PROD_ALT | 66–68 | 同样压缩 Pack 加工可用时段，库存和后续时段吸收该变化。 |
| BAT_OEM | 69–72 | 原 Pack 运输计划被排除，货量在其他时段实现，最优总量持平。 |
| SEAT_UP | 67–69 | 新发运无法在窗口内到货，`has_window_arrival=False`。 |
| SEAT_PROD | 67–70 | 例示的受扰产能行取等，调整 Seat 生产与装配计划后最优总量持平。 |
| ENGINE_PROD | 65–68 | 原名义排程在所有受扰期仍可行，新的容量界留有余量。 |
| GEAR_OEM | 65–68 | 部分原运输量超新界，重排后最优总量持平。 |

例如零缓冲 BAT_PROD 在第 66 期把原排程的 294 件加工量压到 117，仍找到达到名义物料上界的追索。单事件结论本身无法推出双事件结论。Gate 3 已归档每个合法双事件的独立重求，给出了同一固定缓冲下仍达到物料上界的见证。BAT_UP、SEAT_UP 保留为映射认证事件。

## Γ 诊断与 Gate 4 准入

| 预算 USD | Γ=0 | Γ=1 | Γ=2 |
| ---: | ---: | ---: | ---: |
| 0 | 26,448 | 26,372 | 26,372 |
| 250,000 | 26,477 | 26,400 | 26,400 |

两档预算都出现非名义最坏场景，Γ=1 均严格低于 Γ=0。Γ=2 加入的双事件没有进一步降低保证。零预算时，两个单事件独立最优为 26,372 和 26,380，双事件独立重求得到 26,372。两者的损失在同一重排方案中没有相加。250,000 USD 下，Γ=2 的共同方案含 28 套电芯和 20 件 OEM Q4H Seat，联合事件独立重求仍达 Γ=1 的上界 26,400。Γ=1 归档的另一组最优解含 28 套电芯与 21 件 T1 Q2J Seat。两组见证说明在这对事件和预算上，加入共同扰动后仍能达到单事件集合的服务上界。 [Γ 比较](../experiments/v321_gate35_risk_effectiveness/evidence/gate35_gamma_diagnostic.csv) · [逐场景独立重放](../experiments/v321_gate35_risk_effectiveness/evidence/gate35_diagnostic_scenario_service.csv)

**`GATE3_DIRECT_DE = PASS`，`RISK_SET_DISCRIMINATIVE = FALSE`。** 当前选定的诊断风险集能区分名义与单事件服务，尚未观察到 Γ=2 相对 Γ=1 进一步收紧。按本轮准入标准，暂不建议进入 Gate 4。事件网格无法据此解释为实测频率、停供强度或真实恢复曲线。本次未调整已冻结目录，也未启动 Gate 4。

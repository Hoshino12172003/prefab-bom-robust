本诊断冻结在 Gate 3 提交 `c4dc91ddec1f306f50aa8473b6e739ba471c6372`。准备网络、时序、91 个位置、BOM 和资本口径由 Gate 3 原实现提供。认证目录和历史证据随原分支保留。

## 诊断设计

先分别固定 Gate 3 的零缓冲和 29 套电芯方案，独立优化名义和每个原子事件的追索。严格可比名义审计沿用 Gate 1 的 JIT 库容；事件差分和阈值扫描沿用 Gate 3 的 δ=0.5，使各自基准与事件库存界一致。名义容量表反映一组可行最优排程。行约束在该排程取等、事件排除原排程、事件降低全局最优交付分别记录。

强度扫描固定五个资源的 Gate 3 开始期和恢复期，穷举 6 档 availability 和 5 档 duration 共 150 项。临界值定义为对同一资源及持续期，从高可用率到低可用率第一个严格降低最优交付的网格点。超过运营窗口的周期按 Gate 3 规则截断。

预先确定代表事件选择规则。按 BAT_PROD、BAT_OEM、SEAT_PROD、ENGINE_PROD、GEAR_OEM 顺序，取最先有影响的两个不同 BOM 分支。每个资源先选最短有效持续期，再选该持续期下最高的有效可用率。预算响应使用两事件的 Γ=1 风险集。Γ=0、1、2 在 0 和 250,000 USD 两档比较。整个网格与代表事件均为 `DIAGNOSTIC_SCENARIO`。

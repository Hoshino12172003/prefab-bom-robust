# V3.3 恢复期词典序模型规格

V3.2 的准备网络、91 个位置、BOM、成本价值参数、风险定义和信息时序保持原有定义。原订单及承诺日仍在第 61–74 期。所有场景分享同一准备决策和第 60 期库存。

## 清算窗口

程序遍历原料—物料—装配组有向状态图，计算每个外部入口或内部状态到合法装配的最长路径。以第 74 期为边界，尾窗长度取 23 与最大路径提前期的较大值。该窗口保证在边界发运的一条物理路径有相应时间跨度。实际交付仍依赖库存、能力和风险，程序允许最后一期留有积压。原历史在途按发运日加弧提前期入账，包括第 74 期以后到货。

第 75 期起的名义弧资源能力以第 61–74 期能力日历循环，沿用项目已有的周期延拓口径。本次用作 `CERTIFICATION_SCENARIO`。源表给定的 SKU 与组计划限额仅适用于有原始记录的时段。尾窗没有新订单及到期日。风险曲线按扩展后的时期展开，恢复后可用率复原为 1。越过期末且无清算用途的新发运可省略。

## 三个精确目标

1. 最大化最坏原定义按期服务 `rho`。只有到期日及以前的交付计入 `OT`。整数加权交付量乘以固定需求分母后用于优化。
2. 固定所有场景的交付整数下限为一级最优保证。最小化最坏累计订单期积压 `tau`。逐组从到期日到尾窗末期累计 `D_g − cumulative_deliveries[g,t]`。
3. 固定一级与二级的精确整数界限，最小化已有成本。两个 epsilon 均取 0。材料按原 V3.2 价值，期末战略电芯用完整 kit。已知类别材料的持有按 V3.1 规格原有的年率 10% 和每日 `1/365`，计准备期持有与最坏场景运营期持有。最坏持有费用的辅助上界为连续变量，三级最小化时在整数物料解上取各场景持有费用的最大值。不拆分电芯 kit 估值为单种电芯单价，逐期电芯在制持有留作缺证项。位置增量沿用证据不足时的基准设置 0，扩容未启用，增量运营单价缺证。保留各项披露，目标经济值为可计量项的部分合计。

按期交付仍使用原精确 BOM 签名与到期日订单组。逾期交付可将 BOM 和权重完全相同的已到期队列合并，逐期以待交付到期量为上限。逾期队列使用相同 SKU 和装配能力，所有同权重且已逾期的订单在同一交付期减少相同的积压。可用最早到期优先将整数逾期数量还原到原组。平均及最大迟延以此确定的回放口径报告，仅包含实际已交付的逾期单。期末未交付订单继续累计至最后一期。BEV 与非 BEV 只用于暴露指标。

## 事件与预算冻结

使用 Gate 3.5 已验证有效的两个代表事件 `BAT_PROD_D5_A20`、`SEAT_PROD_D1_A40`，第三事件在 ENGINE_PROD 与 GEAR_OEM 已有效的网格点中按最短有效持续期、最高有效可用率选择，即 `GEAR_OEM_D2_A20`。这给出 1、4、7 个嵌套场景。核心三级求解取零资本预算以辨别风险后恢复；另在 Gate 3.5 的两事件集与 250,000 USD 档检验正准备决策下的一级回归。单独对 BAT 及 BAT+SEAT 在同一零缓冲条件下依次求三个目标，以对比各自最优恢复。在同一级服务保证下，按 `rho` 越高越好、`tau` 越小越好的顺序比较 Γ。

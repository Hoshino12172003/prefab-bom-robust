# V3.3 四机制同实例对照

使用 Γ=1 的 11 个正式场景和正式网格中 229,310.54 USD 的 29-kit 锚点。这一实例在 PR #9 未运行，因此五套已经认证的历史实例均无需重算。四种方法在同一主机上串行、独立起进程，使用相同冻结模型、预算、Gurobi 13.0.1、单线程、Seed 0、零 MIP gap、180 秒单 MILP 上限和 12 GB 软内存上限。方法全部以 11 个原场景重放。计时单独记录迭代 Master、迭代 Oracle、独立重放和全程。

复现时分别用 `--method plain|dominance|bounds|combined` 运行 `experiments/v33_gate4_enhanced/benchmark.py`，每次给不同输出目录。之后执行 `experiments/v33_gate4_enhanced/summarize.py --runs <parent-dir> --out <new-dir>`。统计脚本检查模型输入、场景协议、预算、运行参数和软件环境一致，同时核对三级目标、独立重放残差和原始优化 gap。

速度比是相同实例 Plain 总墙钟除以各方法总墙钟。Oracle 调用降幅相对 Plain，只计迭代中的查询。独立认证所需的全场景回放次数单列。每方法一次运行，适合比较调用数量与该次耗时，可重复性能和置信区间待独立样本复核。

四种方法的三级目标均为 `(17,543 辆，86,170 车·期，187,136,406,279 经济刻度)`。每种方法的 33 次独立追索优化均精确复核原 11 场景，最大回放残差为 0，优化目标实际最大 gap 为 0。可行性查询用同一方案同时验证三个阈值，原始查询状态另行记录。每轮加入的场景和模型大小保存在各方法的 `iterations.json`。

支配法保留了 Plain 首轮发现的重度座椅事件，Master 大小和轮次一致，Oracle 调用减少 53.3%，全程耗时缩短 30.1%。有效界法减少 57.8% 的调用，包含 23 次 Master 见证跳过和 1 次缓存见证跳过，但首次发现的违反是中度电池运输事件，重度座椅事件直到第 6 轮才加入。联合方法移除中度场景，第 5 轮才加入重度座椅事件。其 5 次 Oracle 调用较 Plain 少 88.9%，仍因为更多 Master 耗时高于 Plain。在该实例上，最先发现违反的规则带来的 Master 增长超过减少追索调用的收益。现有数据支持优先验证纯支配法跨实例的表现。

## 排序实验

历史违反仅优先检查已加入 Master 的场景。本轮实现可直接复用这些场景的 Master 见证。因此删除已加入场景后，这条历史规则与按 ID 的固定规则检查同一组待求解场景，二者不存在由此产生的求解先后差异。尚无覆盖多实例的独立训练、验证或测试划分。轻量学习排序的稳定增益和 GNN 的必要性保持 `BLOCKED`。

## 两个中档预算的等价直接展开复核

全展开在 Draft PR #12 保留实际停止证据。这里使用证明覆盖原风险集的代表场景一次性展开，无 C&CG 迭代。复现使用 `experiments/v33_gate4_enhanced/reduced_de.py`，分别指定 `--gamma 1` 和 `--gamma 2` 以及各自输出目录。输入、预算 119,890,028.87 USD、三级原目标和求解器参数沿用上述冻结口径。

Γ=1 使用 5 个代表场景。三级原始最优目标与界分别精确相等，值为 `(18,375, 76,351, 590,764,793,776)`，耗时分别为 4.571、9.967 和 119.432 秒。原 11 场景的 33 次独立重放全部 gap=0，最大残差为 0。等价展开与场景包含证明共同提供中档三级最优值的独立证书。

Γ=2 使用 10 个代表场景。一级在 13.428 秒取得 OT 18,375。二级在同一最优 OT 下以 42.489 秒取得积压最优值 76,351。两级原始目标与界精确相等，gap、行残差和整数性误差均为 0。覆盖证明将该二级最优值转移至原 51 场景。三级运行 180.064 秒触及限时，原始可行值 960,648,425,257、下界 −4,565,893,959,150、相对 gap 575.2929%，标记 `BLOCKED`。完整三级解和对应的全场景重放仍待验证。

这两次复核补上了原先指定的 Γ=1 中档经济最优值和 Γ=2 中档积压最优值的独立数学证据。原始全展开的限时、Γ=2 最高预算经济层的开放界以及 PR #9 的历史状态保存在各自报告。整体 `PLAIN_CCG_CERTIFIED = FALSE`。

涉及冻结协议、Plain 回归、支配映射、阈值与缓存规则的 16 项测试通过。另对四种方法各 33 条独立回放记录按阶段检查场景集合、最坏值、残差与原始 gap，并核对公开证据 SHA-256。

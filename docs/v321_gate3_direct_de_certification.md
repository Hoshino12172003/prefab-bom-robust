## 确定性等价与阶段边界

每个模型只调用一次 Gate 2C 的联合准备网络，共 4,208 个第一阶段变量，包含原有准备流量、库存、kit 及 91 个显式公共期末状态。风险揭示时的总物料为 `CommonOpening60 = I0 + b`，其中 `b` 来自准备期终端增量库存。117 条原历史发送承诺保留，按原提前期记入未来到货。每个场景的第 61 期平衡使用相同公共状态的同一个变量。无场景特定准备变量。第 61–74 期每个场景有 12,052 个独立变量，分别覆盖风险后的运输量、生产量、库存和按期装配交付量。

每个场景使用同一网络、订单和约束结构，风险仅改变逐弧逐期能力。整数流的能力 RHS 取风险后实数能力的下取整。名义对照沿用 Gate 1 的零预算、OEM Seat 零池和技术库存处理。认证中使用的 T1 运营期技术库存上界由可形成的期初库存和运营期合法到货相加。OEM Seat 的四 SKU 使用同一个总库容。

`Sω = OTω / 28000`。最大化整数共同交付保证量等价于最大化 `rho`，因为加权交付量为整数且分母在每个场景相同。对任一固定准备方案，可分场景同时选到独立最优追索，故可行共同保证的最大值是这些最优值的最小值。认证包含名义对照、两个事件预算和三档认证资本。诊断预算只约束 V3.2 材料价值，电芯按完整 kit 计价一次。

## 证据边界与复现

事件幅度、恢复与预算是认证情景。当前各场景最优服务并列，结论限于阶段隔离、守恒、风险映射与有限场景等价。公开数据仍不能识别风险前实测剩余能力、真实库容及事件发生率。没有做完整风险集的分离或验证。

运行使用 Python 3.12.7、Gurobi 13.0.1，单线程、seed 0，零 MIP gap。Gate 3 与历史 Gate 2C 共 15 项回归通过，包含读回实际 MPS 并核对九个场景的首期公共状态系数。输入、配置、代码哈希及证明文件见 [Gate 3 证据目录](../experiments/v321_gate3_direct_de/evidence/)。发布日志中的本机路径和许可证标识经过脱敏。

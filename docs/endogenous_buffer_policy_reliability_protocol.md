# 内生缓冲政策可靠性预注册

本协议由 V2.5 Phase 2.0 冻结。以下 A–I 与退化复核均未执行。实施依赖正式成本、预算、情景及求解认证获得后续授权。研究对象为专用保护覆盖，主计数 `Z` 是保证按期履约的整数 VIN 数。

| 测试 | 预注册核查 | 记录和判定 |
|---|---|---|
| A 最优面与唯一性 | 先认证整数最优计数 `Z*`，要求有原始可行解及整数目标上界。将整数计数门槛设为 `Z*`，固定同一环境，分别求三种变量的最小值和最大值并各自认证 | 报 `[L_C,U_C]`、`[L_T,U_T]`、`[L_O,U_O]` 及端点的完整组合。三对均相等才有唯一组合。端点属于各自的可行见证，不能拼接。避免用四舍五入的比例固定最优面 |
| B 近优稳定性 | 对 `ε=0.001,0.005,0.01`，要求 `Z≥ceil((1−ε)Z*)`。使用有理数计算门槛，再对三种变量各求最小/最大 | 记录整数门槛及各端点组合、服务和预算。小损失即可换成实质不同组合时，结论限于最优政策的可替代性。若门槛因整数性与最优值相同，如实报告 |
| C 预算响应 | 成本校准后冻结严格递增的多级预算。同一环境只改变上限，核查 `Z*(B_{k+1})≥Z*(B_k)` | 报组合、使用额和松弛、区间新增车辆数及每预算单位边际增量。只要求最优计数单调 |
| D 风险位置 | 固定同一需求与成本基准，覆盖无扰动、L1/L2/L3 单层和组合场景。分别求目标及政策集合 | 记录作用节点、序列、暴露状态、计数与最优/近优组合。组合风险下使用同一套情景流同时兑现各约束。结构恒同时启动退化审计 |
| E 成本比响应 | 对 `c_T/c_C` 和 `c_O/c_T` 做依据明确的区间敏感性。冻结比率网格、绝对价格基准和预算口径后求解 | 分类报告组件、T1 Pack、OEM Pack、混合或无投入区域，区分严格占优、并列和不确定。合理区间内始终单一时进入物理支配检查 |
| F 提前期响应 | 先采用源 20/1/1。后续每个变化须有依据并标记 `SCENARIO_ASSUMPTION`，区分单变项和联动敏感性 | 报各层时点、跨期可用性和预算/风险不变的比较。提前期跨越窗口时专门检查协议适用性 |
| G 数学支配 | 对总被选的状态尝试构造同成本或更低成本、所有情景不降服务的替换映射，并复核库存、现金、风险和共享能力 | 若 `c_O≤c_T`、OEM 无额外空间/持有负担且替换可行，逐单位将 T1 Pack 改放 OEM 可以免去运输等待及 L3 暴露。证明必须检查所有期的 OEM 占位与收货，不可只比较距离。成立时标 `MODEL_STRUCTURAL_DOMINANCE` |
| H 算法一致性 | 算法获得授权并实现后，在可认证实例上比较 Direct full-scenario MILP、Plain C&CG 和 BR-C&CG。用同一输入和独立回放证实可行性、目标及上下界 | 三个认证最优计数须相等。不同整数解若都达到同一认证计数，检查是否属于同一最优集合。可行性失败、证书不足及经证实的次优分开记录 |
| I 跨实例结构 | 后续预先冻结多个规模与来源保持规则，分别保留源派生订单子集与可扩展计算基准的标签。保留 BOM、资格、来源拓扑和需求结构，明确扩展规则、随机种子及变更量 | 只用于计算扩展性和次级政策稳定性检验。独立标记原始 3,003 VIN 主实例，不能把扩展样本解释成额外历史案例 |

每个环境须保存数据及参数哈希、软件版本、求解状态、目标值和最优界、约束复核及所有政策端点。未认证的环境标明求解边界，不能用一个可行解宣称唯一。先定义等价服务计数和最优政策集合，再讨论管理解释。零投入且服务为零的环境应单独报告，不计为单一正投入位置的证据。

若单层和组合风险、预算、严重度、持续时间、成本比与提前期在有依据的范围内变化后，最优政策集合仍长期只含同一个正投入状态，标记 `HOLD_BUFFER_FORM_POSITION_DEGENERATE`。依次检查价格支配、物理转移、提前期/窗口、风险作用范围与库存位置。保留条件与反例。审计不得用强制正投入、份额或挑选风险数值改变退化结论。

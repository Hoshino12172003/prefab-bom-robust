## 上界、下界与逐阶段验收

受限 Master 从 NOM 开始，每轮重新构造一套共同准备网络和已加入的追索块。以固定相同可行域的三个精确目标顺序求解。大小由实际矩阵读取。每次只加入一个有证据证明违反当前保证的场景。默认 Gurobi 启发式保留，未设置手工 MIP Start。Oracle 串行独立建模，不缩减合法场景，不共享跨轮求解结果或情景池。

设 `Q_s(b)` 是固定准备状态下场景 s 的最优 OT，`r_k` 是受限 Master 的 OT。完整检查每个 `Q_s(b)`。首先按较低 `Q`、相同最坏 `Q` 上较高的最小积压、场景 ID 排序。若某场景可交付量小于 `r_k`，加该排序首位。受限 Master 的 `r_k` 是全问题一级上界，已评估候选中 `min_s Q_s(b)` 的最大值是一级下界。

一级界闭合后，对每个场景在共同 `OT ≥ r_k` 下最小化积压。该检查覆盖自有最优 OT 高于 `r_k` 的场景，因为它们也必须满足共同积压约束。受限 `tau_k` 是此条件下的下界，固定 `b` 的最大全场景最小积压是上界。出现违约时加条件积压最高的场景，同值按 ID。

一级和二级均闭合后，再在共同 `OT ≥ r_k` 和 `A ≤ tau_k` 下逐场景求最小持有成本，验证完整经济上界。经济违约场景按 ID 选择第一个，作为受限模型遗漏的可行性约束。风险排序不使用成本。该检查保证最终三级值可对照完整 Direct DE。风险排序首位已在 Master 时仍执行这些条件检查。

最终用同一第一阶段见证开启一轮全新模型进行全部场景复算。服务和积压以整数单位比较，货币目标以 `1/365000 USD` 为证书刻度。独立复算库存与 BOM 守恒、按期口径、库存界和风险产能。只接受 Gurobi `OPTIMAL`、零 MIP gap 和误差检查通过的解。认证设置继承单线程、180 秒单个 MILP 限时及 12 GB 软内存上限。资源停止的目标不会生成切入场景或认证值。

## 初次运行与数值修正

初次 Γ=2 中档和零预算的单场景 Oracle 积压目标分别给出可行值 87,901 和 33,304，Gurobi 状态为 `OPTIMAL`，但直接目标表达式所报下界分别为 87,900.2 和 33,303.2，原始 gap 非零。按零 gap 门槛停止对应算例。重试用显式整数变量等同于原积压表达式，以保留整数目标刻度。矩阵中每个订单交付仍为原整数变量，积压等式对每个旧可行解确定唯一扩展值。

Γ=2 最高预算初次运行触及服务子问题限时，重试通过该子问题后，经济子问题报可行值 100,661,744,996 刻度、原始下界 100,661,744,995.99998 刻度和非零 gap `1.52e-16`。随后只重试此算例，在固定方案 Oracle 中将整数库存与整数成本系数的持有成本内积显式等同于一个整数变量。重试仍在同一子问题报出相同原始 gap，另有求解器关于大整数变量值的警告。最终基准代码撤回持有成本等式，保留积压整数目标等式。求解器设置与证书阈值全程一致。归档保留全部尝试及其证据。

## 复现

在仓库根目录提供原 XLSB 和 V3.1 审计包。输入与协议 SHA-256 见各次运行的 `gate4a_config.json`。默认依次请求两个中档预算、零预算、最高预算的六个基准及两个中档 Direct DE。`--cases` 可运行其中任意受限子集。全部六个 C&CG 和两个最优 DE 对照通过后才输出完整认证。

```powershell
$env:PYTHONPATH = '.;src'
python experiments/v33_gate4a_plain_ccg/run_gate4a.py --bundle '<V31_Codex_Inputs.zip>' --xlsb '<original.xlsb>' --out '<new-output-directory>'
python -m pytest tests/test_v33_gate4a_plain_ccg.py tests/test_v33_formal_risk_protocol.py -q -p no:cacheprovider
```

归档的初次运行对应 `f0b431b`，整数积压重试对应 `f72bd64` 并额外指定 `--ccg-only --cases G2_MID G2_ZERO G2_MAX`，整数持有成本重试对应 `011e8e5` 并指定 `--ccg-only --cases G2_MAX`。公开日志将本地路径和许可元数据脱敏。SHA-256 清单覆盖公开后的文件字节。

上面的 pytest 命令实际通过 13 项，覆盖冻结协议、场景新增、条件积压、经济可行性、零 gap 门槛、完整回放与公开证据哈希。测试退出码为 0。

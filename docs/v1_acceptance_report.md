## 2. 模型与源码对照

| 数学条件 | 验收证据 |
|---|---|
| 事前库存、签约、预留、事前预算和不可预见性 | 直接模型与 C&CG 对所有场景使用同一组决策，独立模型固定两法各自的方案再重建全部场景 |
| 名义全额履约、订单平衡和装配能力 | 名义 LP 单独求解并复算实际流，投影模型用常量固定名义交付，并以变量上界表示风险场景的订单上限 |
| T2 产能、池级共享 T3 容量、资源投入与资格 | 各供应商产能、每池汇总量和逐弧投入分别复算。三族算例的两个物理池共享同一 T3 风险坐标，其中 MV 同时消耗两池资源 |
| 备用储备与损失上限 | 三族案例检查共享池和备供资格。专门构造有储备且需求超过正常能力的无损场景，验证备用为 0。全损时验证启用量截于 0.75 的预留量 |
| BOM 齐套和成本口径 | 三族案例同时检验 HV 的两项 BOM、库存成本、合同费、预留费、名义采购及风险启用费。去掉辅助组件库存或把运营预算降至 4.49，三个模型均判不可行 |
| 联合分类保障与 Phase-I | 三族案例使用单一追索计划。在纯 T3 反例下逐族均可满足，联合最小缺口为 0.5，独立硬约束模型判不可行 |
| 连续风险极点与停止条件 | 独立用有理数求盒边与预算平面的交点。检查 1–4 维、整数及分数预算、靠近整数的浮点边界。预先计算场景数并测试超限不进入物化 |

Phase-I 可取零生产、零交付、未交付等于需求、缺口等于各族下限，因而在有效输入下可行且目标有限。风险只仿射进入约束右端，固定事前方案的 Phase-I 值函数是凸的。将任意风险写为极点凸组合，凸性给出该点缺口至多为最大极点缺口。整数预算的顶点均为二元点。分数预算需要保留沿预算平面的非整数顶点。

独立 Gurobi 模型没有调用生产约束构造或生产枚举器。它令每个合格弧的最小正常流等于该弧实际投入需求减去备用流，并消去正常流和未交付量。给定生产模型的可行解，可先把超出投入需求的备用流降至投入需求，再把正常流降至剩余投入，容量和费用限制均保持可行。由投影解可令正常流等于投入减备用，未交付等于订单减完成量，恢复生产模型的可行解。因此该投影保留可行性与目标。另用纯算术复算两种生产算法实际返回的名义块、主问题场景块和所有顶点的 Phase-I 流。

## 4. 失败调查与验收边界

原有 22 项测试在修复前通过。新加的首批 6 项回归全部失败，定位到近整数分数极点漏列或越界、输入负数与非有限值遗漏、对“≥”服务行的松弛方向读反、模型构造阶段的许可证异常未捕获。修复枚举拆分和预计数、输入域检查、Gurobi 行/界/整数残差读取、建模和求解异常处理。认证还新增真实求解界检查，分离失败会撤销最优标志。首个三族反例把 HV 的 T2 单点冲击混入单族竞争对照，导致 HV 独立缺 0.5。用固定纯 T3 场景隔离竞争，并保留联合 T2/T3 正例。原有测试预期未改，认证阈值未放宽。

T16 的 0 秒时间限制由真实 Gurobi 触发。许可证失效和数值分离失败用受控异常注入复核，实际许可证正常。本机裸 `pytest` 命令的启动器不在 PATH，`python -m pytest` 可正常执行。

尚待业务确认的是独立备用是否应限于当期同池损失、真实组件资格与资源计量单位，以及连续交付近似是否满足实际装配要求。极小分数预算按输入浮点值完整枚举，数值求解结果仍受上述容差约束。超出场景阈值时精确验收没有可用分离路径。

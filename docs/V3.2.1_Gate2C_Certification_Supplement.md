# V3.2.1 Gate 2C 认证口径补充

V3.2.1 仅修正 C2C-07 和 C2C-10 的认证语义。V3.2 数学模型原样保留，包括 91 个候选位置、BOM、提前期、联合库存守恒、共享能力及 α、H、δ、κ 的定义和求解网格。

V3.2 原 C2C-07 和 C2C-10 规则施加了超出模型定义的限制。前者将依赖库容情景的投影跨情景使用，后者将具有比例等式的三个电芯位置当作独立决策。原失败表及原验收报告随 PR #3 保留。 [原失败证据](../experiments/v32_gate2c_joint_preparedness/evidence/gate2c_bmax_crosscheck.csv) · [V3.2 规格](V3.2_Final_Mathematical_Specification.md)

## C2C-07 同情景投影

对同一情景 s，分别最大化各独立位置的保护库存，得到 Bproj[np | s]。投影与联合解须使用同一 H、α、δ、库容情景、κ 以及逐项有效库存上限 K_eff。情景身份含期中和终端上限、共享 OEM Seat 库容和整数资源上限。检查每项 b_joint[np | s] ≤ Bproj[np | s]。诊断预算进一步收紧物理可行域，预算解可使用同物理情景的投影作为上界。冻结 Gate 2B 数据只用于 C2C-10 回归。

## C2C-10 可比投影复现

保持原 Gate 2B 的 α=1、δ=0、仅技术上限及五个 H。普通位置仅开放该位置的终端保护库存。电芯以完整 kit 作为一个投影单位，允许三种电芯按 10:6:4 同时为正，最大化 x_C，再按比例与冻结投影逐项核对。字面单电芯试验的历史记录继续保存，其结果退出新版通过判据。

## Gate 3 准入

符合原前置关卡状态及 `EMPIRICAL_RESIDUAL_CAPACITY = NOT_IDENTIFIED` 时，只有 V3.2.1 的 C2C-01–10 全部通过，才标记 `READY_FOR_GATE3 = TRUE`。准入标记属于本轮交付，Gate 3 的执行另行处理。

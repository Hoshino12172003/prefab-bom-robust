# 小规模精确求解验证

## 方法

直接展开模型同时包含全部 T2×T3 极点场景的追索约束。C&CG 从零风险场景开始，每轮对当前方案逐一解完整极点集的 Phase-I，加入最大缺口场景；只有最大缺口不超过 (10^{-7}) 才停止并认证。两者共享数据与单场景约束构造，但主问题场景组织和迭代路径不同；解析值提供第三条独立核验线索。

## 算例 A

全部未列参数已在 `example_a()` 明写：两个产品需求各 1、两种专用组件、两家 T2、一个共享 T3 池，T2 产能均为 2，装配能力 2，运营预算 10，库存上限各 1，正常采购与备用启用费均为 0，Γ2=0。T3 极点为 0 和 1。

当 ξ=1 时正常 T3 能力损失 2。若全交付，要么用两单位专用库存（成本 6），要么预留两单位备用（成本 4），或混合（每替换一单位备用为库存成本从 2 变为 3）。故解析最优为 (r=2,x=0)，投资 4。

实际：直接展开 `OPTIMAL`，目标 4.0，最坏缺口 0，方案 (y=1,r=2,x=(0,0))，运行 0.0094 s；C&CG `OPTIMAL`，目标 4.0，最坏缺口 0，2 轮，运行 0.0052 s。

## 算例 B

全部未列参数已在 `example_b()` 明写：单产品需求 1，T2 产能 2，装配能力 1，运营预算 5，库存/备用上限各 1，正常采购和启用费 0，Γ2=0。连续 T3 集合的极点为 0 与 0.5。

最坏极点损失正常能力 0.5；预留 0.5 备用恰好替代损失，成本 (0.5\times1=0.5)。用库存替代的同等保障成本为 (0.5\times2=1)。故解析最优为 (r=0.5,x=0)，投资 0.5。

实际：直接展开 `OPTIMAL`，目标 0.5，最坏缺口 0，方案 (y=1,r=0.5,x=0)，运行 0.0013 s；C&CG `OPTIMAL`，目标 0.5，最坏缺口 0，2 轮，运行 0.0097 s。

## 残差与认证

两个模型的约束残差由 Gurobi 约束 Slack 独立扫描，pytest 要求不超过 (10^{-6})；本次均满足。直接展开和 C&CG 的目标误差为 0，最坏服务缺口误差为 0。认证仅对当前小实例、当前连续 V1 与枚举阈值内的完整极点集成立。

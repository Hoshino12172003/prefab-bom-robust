# V3.2.1 Gate 3 有限认证事件目录

冻结八个原子事件。事件只作用于原模型的资产，包括 Battery 上游运输、Pack 加工与送 OEM，Seat 上游运输与成品加工，Engine 生产及 Gear 送 OEM。每个事件的强度、开始期、持续期和恢复期属于 `CERTIFICATION_SCENARIO`。参数以事件模块和运行生成的逐期目录为准。

设可用率为 a，事件在开始后的 d 期使用 a。随后第 k 个恢复期的可用率为 `a + (1−a)k/(r+1)`，k=1,…,r。再下一期恢复至 1。持续和恢复均包含在同一原子事件预算内。名义能力取源 XLSB 的运营期逐弧逐期能力。风险只乘以当期能力，保留产品、组、库存约束及第 60 期前历史承诺。Battery 和 Seat 上游运输提前期分别超过 14 期运营窗口，相关新发运在窗口内无法到达。目录中这两个事件保留用于检验资源及轨迹映射。

同一事件只能选一次。同一资源的事件活跃区间（扰动和恢复）相交时禁止组合。不同资源可以同时发生，无论属于生产或运输。上游和下游跨层事件允许联合。先枚举所有大小不超过 Γ 的无重复子集，再按兼容性筛选。只有完整、精确的逐资源逐时期能力向量相等时才去重，原组合与代表向量的映射随结果保存。

准备设定冻结为 H=23、α=0.5、OEM Seat δ=0.5、T1 technical-bound-only。H=23 提供各层准备时间，α=0.5 分配部分名义能力，δ=0.5 启用可审计的四 SKU 共享上界。三个诊断资本预算为 0、250,000、1,000,000 USD。冻结正库存见证包含 10 个 OEM Pack、两个各 10 件的 OEM Seat SKU 和 2 套上游完整电芯 kit。仅名义、零预算对照采用 Gate 1 的 δ=0 和同一技术库存界。

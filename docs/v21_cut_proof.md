# V2.1 强化割证明与适用条件

## 总量割

实现权威模型式（38）—（42）。只在族内所有产品的工序2都消耗组件 j，且全部合格 j 生产者都消耗池 k 时生成证书。证书包含 h/j/k、正的最小工序2需求 a、正的最小投入 b 及需要保障的组件量 L。无生产者或任一严格正值条件失败时跳过。

先扣除期初成品和保证在途成品的宽松数量上界，剩余交付必须通过本窗口工序2，至少需要 L 单位 j。现有组件供应上界 E 包括所有地点的期初与新增组件、T2 已产组件以及保证在途组件。其余 j 必须新产。将池 k 的输入库存守恒式在供应商和时间上求和，新产 j 的投入至少为 b 倍，正常发运受总 C 限制，备用累计发运受 r 限制，非负期末库存与其他消耗只会降低可用于 j 的量。因此 L ≤ E+U/b。所选风险必须属于允许集合。

该约束是物料守恒与产能约束的投影，完整场景已包含时被对应追索块隐含。它与 LP 对偶/Benders 投影有直接重叠。

## 时间可达性强化

对 h/j/k 证书，令截止于工序2的最晚可用时期为该族各产品 `due-LF` 的最大值 D。在组件 j 的地点转运有向图上求到厂内 a 的最短路径，结合每条 T2 发运路线的正提前期，得到每个供应商 s 的最小组件运输时长 dist(s)。

正常池 k 在时期 t 的发运，只有存在一个合格 j 生产者 s 满足

`t + L3N(k,s) + dist(s) ≤ D`

时才可能用于该族按期工序2。求和上界 U 中，只保留满足此存在条件的时期的正常池 C。若没有任何备用弧满足 `1+L3B+dist ≤ D`，连最早备用发运也无法赶上工序2，故从 U 中去掉 r。若有可达备用弧，保留完整 r，仍是宽松上界。所有期初资源和保证在途仍保留原上界，以防误删已经在途中或较近位置的投入。得到 Utimed ≤ U，将式（42）中的 U 换成 Utimed。

证明依赖正运输提前期、工序2在厂内完成以及所有新产 j 的合法组件路线均在图中。任何从新 T3 发运最终转为工序2消耗 j 的实际路径，其累计运输时长不小于图中最短时长，因此被删除的发运不可能服务该族截止期。共享正常产能每期仅计一次。丢弃其他产能、加工耗时和非 j 用途会放宽上界，因此这个替换保持必要性。工序1的已有 WIP仍需工序2组件，不能绕过该证明。

## 实际核验

G6 在 9 个库存/预留格点上分别完整枚举 12 个风险极点求 Phase-I。原模型鲁棒可行的格点均满足两种割。零库存、零备用且完全中断违反总量割。备用提前期变成 2 后，总量割满足但交付缺 1，时间割能够识别。将某个合格生产者的 b 改成 0 后，自动停止生成该证书。

认证状态为 `PASS_V2_CUT_VALID`。测试规模和证明只支持当前连续基础模型与上述前提。实际配对效果见算法消融报告。

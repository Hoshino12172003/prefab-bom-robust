# V2.1 数据字典与放行条件

`Data` 的所有参数组、索引域、费用及提前期必须显式给出。稀疏零值也必须占据声明的参数索引，未知参数组和越界弧会被拒绝。示例由 `examples.micro()` 生成，完整输入快照存放于验收输出目录。

| 数据 | 单位和验证 |
|---|---|
| A、A1、A2 | component-unit / product-unit，非负、有限，逐项 A1+A2=A，绝对误差阈值 1e-10 |
| T2 a、K、工序 tau、P | work-unit 口径，按供应商或工序独立约束 |
| b、C、G、R、r | pool-specific-unit，各池守恒。正投入只能位于 E 与 N∪NB 的合法关系 |
| 库存、生产、加工和交付 | 连续数量，非负有限。组件与成品采用各自计量单位 |
| 运输提前期 | 整数 period，跨节点至少 1，最终客户路线允许 0 |
| 截止期 | 1 到 T 内的整数，最终发运必须赶上实际到货截止期 |
| 风险 | 连续 [0,1]，预算有限非负。预算超过节点数时按相同盒集合处理 |
| 财务 | currency，全部费用非负有限，费用参数与合法变量域严格匹配 |
| 存量与保证在途 | 每个实物批次有唯一 ID、类别、索引、数量。重复 ID 拒绝，PF 过量和逾期拒绝 |

单位声明是输入合同。真实物理单位换算和备用来源独立性仍需业务文件支持。当前数据全部属于 D 级合成，工序 BOM 也是合成划分。实物批次 ID 必须由数据源赋予，若用户为同一物料伪造两个不同 ID，仅凭数值无法自动判定。

基础输入拒绝 T2 与外协同名实体，以防在未建共享产能/风险的条件下重复创建容量。库存容量启用属于扩展，会被明确阻止。每个调用风险也校验节点域与预算成员资格。

G0 测试实际覆盖 BOM 不一致、零跨节点提前期、重复批次、强制客户在途超订单、逾期到货、非法备用弧、非有限费用及仓容扩展。G2 检验保证在途 R/I/WIP/客户的合法到货，不将其再次作为期初存量。基础预算 0 的零动作例即使有高会计持有费也仍取得有限 Phase-I 最优值。

# 上游保护物料形态审计

选项 A 保留整数 \(x_C\)，每单位分别加入 10、6、4 件组件。选项 B 分别决定三个非负整数保护量 \(x_{Cj}\)，需要三项价格和各自采购可用量或业务资格，且在第二阶段继续使用完整 BOM。若令 \(x_{Cj}=a_jx_C\) 并令三项加权成本之和等于一套费用，两定义等价。解除比例约束会扩大物理选择，但需要独立成本证据才能比较相同预算下的政策。

已核验的公开 XLSB 电池组件直接母项仅有 BEV Pack，相关车型共享同一 Pack。车辆配置差异主要来自其他直接部件及到期日。正常来料与保护可以共同补齐一套，因而组件级补货可能消除 SKU 尾数或异质中断产生的缺料。例如常规库存 \(9,6,4\) 只需补 1 件第一种组件即可新增一套。这个例子是物理可行性说明，公开候选 L1 对同一收货池的三个 SKU 共同衰减。源数据不支持跨电池型号或跨直接母项的额外配置自由度，也没有分 SKU 的可比采购费用或风险校准。

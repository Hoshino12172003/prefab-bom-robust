# C&CG 结构准入复核

| 条件 | 当前证据 | 判定 |
|---|---|---|
| 有大量合法组合轨迹 | 候选 Γ=6 有 287,443 条，历史有效右端项 38,527 种 | 候选计数成立，前瞻有效数待输入 |
| Direct 展开复制完整整数块 | 三选定情景共 227,434 个整数变量 | 成立，证书覆盖所选集合 |
| 固定情景追索无法被简单精确化简 | 一般模型类有三维匹配归约，历史候选在纯服务目标下有精确 JIT 和前缀证书 | 对已验证配置不成立 |
| 最坏情景分离有独立优化意义 | 四个固定历史政策在所选五情景中均由 L1 与 L1+L3 并列最坏，完整前瞻场景最坏服务包络未知 | 尚未确立 |

同时期活跃模式的包含极大性不等于服务函数非冗余。相同有效右端项可安全合并。若允许一般正常状态并保留有限库存上界及硬计划，单纯降低常规固定到货也不保证可行集嵌套，例如减少被强制接收的过量库存可能恢复可行性。故候选计数未用此类规则删减整个鲁棒集合。

本轮没有获得结构准入。后续评估需以已校准的前瞻输入和独立验证的最坏服务包络为依据。经典 C&CG 文献支持方法背景，整数追索和具体分离问题的有效性需要各自证明。 [规模证据](uncertainty_set_size_audit.csv) · [固定政策比较](historical_fixed_policy_scenario_audit.csv) · [Zeng 与 Zhao](https://doi.org/10.1016/j.orl.2013.05.003)

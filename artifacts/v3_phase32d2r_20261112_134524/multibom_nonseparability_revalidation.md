# 完整整数追索的非分离性复验

三个政策取自 Phase 3.2P，求解时固定为 \((915,0,0)\)、\((1338,24,0)\)、\((713,135,6)\)。从完整目录按 3.1R 既有起始日和本轮核心网格选取 B、G、S、BG、BS、GS、BGS，并补入长时长、晚到期和发动机代表。求解前逐个核对合法轨迹、类别 ID 及实际 Gurobi 矩阵的 RHS 变化。 [代表情景](representative_scenarios.json) · [整数求解与见证](fixed_policy_full_milp.csv)

对固定政策 \((915,0,0)\)，选择三次 7 期、50% 损失、突然恢复的合法 `BGS7`。Pack 生产及变速箱运输受扰于 61–67 期，座椅配送受扰于 68–74 期。事件数为 3，峰值并发为 2，累计暴露为 21 个资源日。

| 量 | 准时交付 |
|---|---:|
| 无新增中断 NR | 27,363 |
| 独立 Pack 生产事件 B7 | 27,363 |
| 独立变速箱事件 G7 | 23,350 |
| 独立座椅事件 S7 | 21,350 |
| BGS7 完整整数追索 | **18,600** |
| 独立分支最小值 | 21,350 |
| 相对 NR 的独立损失相加 | 17,337 |
| 冻结电池递推，仅保留电池投影 | 27,363 |
| 以独立分支到期前缀为状态的一维 DP | 21,350 |

对三个隔离情景逐一求每期到期订单的最大累计准时量。将这些前缀上界取最小后应用冻结的一维递推，结果高估联合解 2,750 辆。独立损失相加低估联合解 1,263 辆。同一个电池投影在 B7 与 BGS7 的完整追索值分别为 27,363 和 18,600，电池递推的适用前提被变速箱和座椅风险破坏。结果针对这四种被检验的化简，未建立一般计算复杂性下界。 [逐期 DP](scalar_due_prefix_dp.csv) · [前缀求解日志索引](prefix_solver_calls.csv) · [联合化简对照](nonseparability_comparisons.csv)

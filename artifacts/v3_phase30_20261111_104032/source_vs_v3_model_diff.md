# Quetschlich 源案例、公开 XLSB 与 V3 差异

| 对象 | 可核查差异 | V3 处理 |
|---|---|---|
| Eq. (10) | 逐期文字与可跨期重排冲突 | A 固定承诺日，B 用 VIN 总装配与缺口平衡，出库按 Eq. (11) |
| §4.9 与图 10 | 文中 A 的 η=200 和 B 的 η=0 与图注对调 | 两个场景分别跑两种权重 |
| Eq. (17) | 论文 D60 第 65 期固定 40，公开品项上限 22 | 公开上限、物理容量、独立计划承诺各用单独约束 |
| Table 7 | 电芯上游第 67 期展示 490，公开弧容量 2,058 | 原始 XLSB 容量，沿用 Phase 1.10 |
| 物料输入 | 49 条 BOM 自指与同组运输操作并存 | 原始行保留，运输按 operation 1:1，仅不同母子关系参与制造 |
| 通用运输装备和共同产出 | 公开车型尺寸全零且 α=0 | 实现相应约束，源无激活行 |
| 缺失的公开初始项 | 仅提供稀疏期 60 字段 | 沿用复现用稀疏零政策并保留来源缺失边界 |
| 历史缺口 | 公开期 60 数据带已发生短缺，860 的恢复量和物理单位仍无唯一证据 | 原快照、原在途用于来源复现 |
| 正常状态和额外投资 | 公开历史快照无法给出前瞻正常状态 | 前瞻接口要求有来源的正常库存和到货，缓冲另加 |
| 产品和日期索引 | 部分 VIN 的全部运营和目标系数一致 | 求解压缩等价类，逐 VIN 展开，另可显式编制索引 |

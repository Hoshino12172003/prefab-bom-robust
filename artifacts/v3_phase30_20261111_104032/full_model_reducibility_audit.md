# V3 全网可约性复核

从 A 的 28,000 VIN 整数见证提取两项换单。每项保持固定开盘状态和缓冲，Pack 路径不受影响。

- VIN 64001 与 66333 的承诺日分别为 61、62，具有相同直接 BOM。交换二者在装配和出库上的日期，发动机、齿轮、座椅、Pack 及 OEM 日总量完全相同。库存路径可相应重标号，两个 VIN 各偏离一天。按 ζ=100，B 的目标提高 200。只递推电池可达量无法复算完整目标。
- VIN 64001 与 66001 的承诺日也分别为 61、62，但座椅 SKU 不同。若固定原来料，仅交换装配 VIN，第 61 期额外需要一件 Q2J。源案例 OEM 座椅 JIT 期末库存为零，替换后此件库存为 −1，违反整数物料平衡。

B 的 uc 按 OEM 总装配量定义，BEV 和非 BEV 共同竞争同一逐期能力。移动 VIN 联动日期、BOM 需求和库存轨迹。固定投资后，Phase 2.2 的单 SKU 前缀服务式不足以描述本次恢复的全网追索。上述反例针对具体化简，其他精确聚合、网络形式或专用方法仍待研究，算法必要性尚未认证。 [换单证据](full_model_reducibility_witnesses.csv)

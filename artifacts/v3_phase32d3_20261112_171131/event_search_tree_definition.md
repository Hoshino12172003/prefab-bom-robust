# 固定政策事件空间搜索树

节点保存已选原子事件集合 \(S_N\)、按固定次序尚可尝试的 \(R_N\)、剩余事件名额、已经使用的资源位、活跃至少一次及至少两次的日期位集，以及从父节点继承的服务下界。当前已认证最坏服务量 \(q^{inc}\) 由搜索全局维护并随节点日志写出。

根节点对应无事件轨迹。节点覆盖当前前缀 \(S_N\) 以及该前缀的所有合法后续选择。第 \(i\) 个子节点加入 \(R_N[i]\)，把后续候选限制在序列后缀。删除同一资源、与双重活跃日期重叠或使子空间门槛超限的候选。资源使用、每日活跃数和用于子空间的秩在向下搜索时均不减，因此这些删除不丢失可行的延伸。每个非空合法后续选择按其最早的新增事件唯一分配到一个子节点。节点数与有效 RHS 数可不同，前者保留不同日期重叠关系的原子身份。

实际 Gurobi 求解以当前固定政策和完整物理矩阵执行。合法情景的精确最优值可以更新最坏 incumbent。人工包络解只用于建立下界。两个合法事件组合映射到相同实际 RHS 时复用已认证的整数最优值。同一运行内，包络和合法情景也共用这一缓存。

## 子空间设计

Γ=1 使用全部 355 个 RHS 作为独立逐项 MILP 对照。Γ=2 和 Γ=3 的嵌套梯度以非负局部秩的无进位交错编码定义。各局部名义向量秩为零。以错峰 7 日事件作为各资源的首个非零候选后，再按强度、时长、起点排序。Γ=3 每档均含必须三个事件才能产生的类。独立显式路径从冻结 D-2R 目录取第 N 个秩作为门槛。隐式搜索仅接收门槛和原子目录，不接收该档情景列表。阶梯为确定性验证集。性能和最坏值外推到全域需要独立证据。 [梯度定义](benchmark_design.json)

## 剪枝与前沿

最坏值认证只要求 \(L_N\ge q^{inc}\)。Γ=1 还须找出全部并列最坏 RHS，因此使用严格的 \(L_N>q^{inc}\)。完整节点包络及见证复用见数学证明。顺序由分支优先级、事件严重度、时长和起点决定。种子从合法延伸中用冻结前缀上界排序，种子必须完成完整整数求解才能建立 incumbent。

对于被资源上限打断的全域搜索，保存未完成节点的所选原子、剩余原子、并发状态、剩余名额与继承下界。全局下界为所有前沿下界与当前 incumbent 的最小值。incumbent 是最小化最坏服务问题的全局上界。只有搜索闭合时才能将该值标为全域最坏值。 [安全界证明](event_envelope_bound_proof.md)

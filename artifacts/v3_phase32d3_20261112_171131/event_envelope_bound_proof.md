# 中断包络的整数追索安全下界

记 \(p\) 为实际受风险影响的整数 RHS 坐标，包含电芯收货与五条弧的逐期总容量。固定政策 \(x\)。若 \(p^-\le p^+\)，以下构造从任意可行的 \(p^-\) 追索方案得到一个在 \(p^+\) 可行、交付量相同的方案。

1. 保持全部流量、装配、订单和外采变量。Pack 加工、Pack 运输、变速箱运输、座椅配送和发动机加工的风险行均为非负流量总和的容量上界。恢复容量只放松对应行，且这五条弧均非 OEM 装配弧，未改变未分配装配容量等式。
2. 对每个受扰电芯收货 SKU 及每期 t，将原库存加上截至该期恢复的累计固定收货。该差值是非负整数，恰好恢复库存等式且保持库存下界。其他库存与 BOM 使用量保持原值。
3. 受扰电芯库存的最坏上界由开盘库存、政策额外库存、窗口内全部正常固定收货和可能进入窗口的内部来料上界之和给出。对四个固定政策逐 SKU 检查此和小于对应库存上界。所有电芯受扰状态均无外部采购变量，窗口内可能新增到货的内部发运按原弧能力上界计。于是恢复固定收货后的库存仍可行。

因此 \(Q(x,p^-)\le Q(x,p^+)\)。固定收货写在库存等式里，第 3 步是证明所需条件。库存上界、强制流量或风险映射变化时应重新核验。实际矩阵逐坐标核对覆盖六种资源与人工包络。零流量、零交付方案通过完整矩阵复核，调整电芯库存后在所有非负的核心容量及收货坐标上仍可行。

对节点 N 取

$$
p_N^{env}=\min\bigl(p(S_N),\{p(\{e\}):e\in R_N\}\bigr)
$$

其中最小值逐坐标计算。\(R_N\) 可以包含互斥候选，包络也可同时削减所有这些坐标。任一合法 completion 的 RHS 在每个坐标均大于等于此包络，所以 \(L_N=Q(x,p_N^{env})\) 是该节点最坏值的下界。任何在包络上可行的整数方案的准时交付量也给出安全下界。

## 三档执行策略

- Level 0 使用已验证的零服务整数方案作为结构下界，合法 RHS 的精确值按 RHS 缓存。由日期容量和到期前缀构造的冻结 BTB 界在这里是服务上界，单独无法给最坏搜索提供可剪枝的下界。
- Level 1 使用已求得的相同包络 RHS 值，并尝试把已认证整数方案重放到包络。重放检查全部受影响的弧载荷以及按累计收货差修正的每期电芯库存界。其余矩阵行逐项保持。
- Level 2 仅在深度不超过 1、有至少八个下一事件且冻结前缀上界仍允许剪枝时尝试额外包络 MILP。每运行至多八次。上界用于排除无希望的包络求解，节点剪枝仅使用已证明的下界。

## 事件支配检查

只有同一资源的替换、替代事件活跃日期集合包含于原集合、且替代事件在全部坐标上不弱，才得到全核心域可行的弱支配替换。共享 RHS 但并发状态不同的原子保留身份。弱支配允许最优值相等。完整并列集合与阶梯子空间的准入另外依赖可行性，因此本轮只审计这些替换，没有将它们用于删除节点。 [支配审计](event_dominance_audit.csv) · [矩阵核对](mapping_audit.json)

# 历史开窗下的多 BOM 可约性

全部结果限于 STRESS_TEST_ONLY。令 Q0 为固定政策在无新增扰动时的最优准时交付量，Q_r 为只保留联合场景中分支 r 的冲击、保留完整基模后独立求得的最优准时交付量。以下计算使用相同政策及相同孤立冲击轨迹。

| 候选化简 | 实际检验 | 判定 |
|---|---|---|
| 电池前缀递推 | 调用 Phase 3.1 已证明的历史公式，验证原非电池充足证书 | 无新增扰动及纯电池 80 格完全一致。扩展后的 273 格发生高估；K644_C、BS 高估 898。 |
| 分支独立递推后取最小值 | 每一分支先用完整整数网络计算精确最优值，再取最小 | 84 格失效。即使分支内计算完全精确，标量取最小仍丢失联合 VIN 配额。 |
| 独立损失加总 | Q0 − Σ_r(Q0−Q_r) | 首轮全部一致。追加的 60 格日期重叠测试全部失效；BGS_OVERLAP、K644_C 低估 863。 |
| 一维覆盖、到期前缀 DP | 对每个到期日单独求两分支的完整网络精确最优前缀，再做一维覆盖 | 28 次分支前缀 MILP 最优。K644_C、BS 的覆盖上界 26,465，精确值 25,991。 |
| 普通单商品流的整数性 | 求解保留全量 BOM、SKU、库存和时序系数的 LP 松弛 | 7 个完整 LP 中 3 个比 MILP 大 0.5。去掉联立配套约束的普通流松弛也不能直接给出精确目标。 |

令 D(t) 为 t 到期的 VIN 数，U_r(t) 为只扰动 r 时、最大化到期日在 t 或之前且准时交付的 VIN 数。对 BS，撤掉座椅限产只放宽容量；撤掉电芯到货损失恢复的电芯可留在有足够库容的收货点。故联合方案的到期日前缀必须满足 y(t)≤min_r U_r(t) 和 0≤y(t)−y(t−1)≤D(t)。这些上界随 t 非降，一维递推 y(t)=min{min_r U_r(t), y(t−1)+D(t)} 在该放松问题中逐日取最大可行值。在 BS 上，两个分支分别得到 26,889、26,465，一维动态规划仍只得到 26,465 的上界。保留日期而合并同日不同 BOM 的状态，仍会丢失联合选择约束。[逐日复核](scalar_covering_prefix_dp.csv)

通用动态规划可把每个节点与 SKU 的库存、各提前期队列和未完成的 VIN cohort 状态纳入状态，再以完整整数流量与装配动作转移。这种构造保存了被一维 DP 删除的信息，未证明它能压缩为低维状态或减少计算成本。0.5 辆差距也允许在这些选定实例上取整上界来认证已有整数见证；取整后必然精确的通用证明目前缺失。

**NONTRIVIAL_MULTI_BOM_INTEGER_RECOURSE_CONFIRMED**，证据范围为本次实测的标量化简和未取整 LP。以 BGS_OVERLAP、K644_C 为例，保留同一第一阶段政策，完整整数网络的准时交付 25,991。独立最小值 26,465，独立损失加总 25,128，完整 LP 上界 25,991.5。VIN 分组明细同时保存 SKU 组合、到期日及一个最优分配的差异。上述反例仅需现有 BOM 和供给弧。[整数见证](nonseparability_witness.csv) · [LP 数据](LP_relaxation_audit.csv) · [VIN 明细](vin_competition_audit.csv)

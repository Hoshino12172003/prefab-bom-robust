# Phase 3.2P 审计判定口径

预算、风险轨迹、初始化和成本点以求解前固定的 frozen_policy_grid.json 为准。采用未校准但居中的应力对照作为非极端证据。风险位置采用 50% × 7 日、中心预算、中心成本，比较 R1–R5 的单资源冲击。预算可检验 0.50–1.50 倍中心预算。成本对照在单位价格满足 C≤T≤O 的子域单列。中心 50% 是应力设计刻度，不能校准实际中断频率或强度。R6 的每资源强度与 R1–R5 相同，但合计暴露更高，作为联合机制对照。

每个三元组的非零位置定义代表类别。最优集合以全部情景服务量至少达到已证主目标和第一阶段预算刻画。变量投影给出该位置必用、可选或不可能使用的信息。各投影可来自不同三元组。七个预指定锚点额外逐项核验八种完整支持集的可行性。两个点若一个位置从所有最优政策均为零变为所有最优政策均为正，或两个点的完整支持集互不相交，则可给出强切换见证。单一代表解变化和可选位置变化分别记录。

某位置的精确禁用差为正，或某一环境最优集合中该位置的最小用量严格为正，均能证明该位置在该环境有独立最优价值。用配对环境的受影响容量、收货与库存、完工和装配时序解释机制。服务最优运营方案可能多解，库存账本合并常规和保护库存，净消耗不能任意归因于某一批保护库存。

成本的条件性加密按照冻结协议触发。逐格比较只支持局部离散断点区间。预算上下半个 C 套件成本的对照用于检查可负担整数库存数量对活动状态的影响。
